# Vehicle model assets

`steam-jeep.glb` is an authored Three.js geometry export from `apps/web/src/prototypes/jeepModel.ts`. It contains an empty Victorian steampunk jeep with six named passenger attachment groups, a separate driver group and a hinged tailgate. It contains no raster textures or external-source artwork. See `docs/prototypes/steam-jeep.md` for scale, inspection and limitations. The model preview can generate the same export through Download 3D model.
