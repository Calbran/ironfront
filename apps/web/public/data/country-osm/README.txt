These filtered extracts and adaptations are made available under ODbL 1.0. Each JSON file records the exact query, center, bounds and retrieval timestamp. Source ways and geometry are retained; tags are restricted to building/highway/waterway/bridge/tunnel/access, excluding addresses and personal data. Downloadable source data accompanies the preview. The game's architecture meshes are separate original assets, not OSM building models.

Castle Combe, Bibury and Painswick provide layout references, not geographically exact reconstructions. Model spacing is compressed to 0.55 game units per meter, buildings are selectively omitted for clearance/readability, and architecture is substituted. Coverage is a bounded way-only extract: building multipolygons, terrain height, road restrictions and navigable water crossings are not reconstructed.
