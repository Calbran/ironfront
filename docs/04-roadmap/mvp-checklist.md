# Roadmap

The parallel [miniature city/world roadmap](miniature-city-development.md) covers the Three.js studies, dense districts, terrain-first generation and eventual production adoption. Its visual work does not replace the gameplay milestones below.

## Milestone 1 — Persistent playable proof (current)

Generated continent, map inspection, faction choice, create/join, automated empty seats, basic resources/buildings, persistent orders, combat/capture, land scoring, SQLite storage, and accelerated test clock. See PROJECT_STATE.md for actual validation.

## Milestone 2 — Useful five-minute session

Multiple armies, recruitment and recovery clarity, supply visualization, meaningful aircraft missions, construction queues, since-last-visit grouping and map replay. Measure whether a player understands losses without manual explanation.

## Milestone 3 — Friends campaign

Ready/start lobby, recoverable accounts, pause/admin controls, balanced starting zones, durable production hosting and backups, reconnect/browser coverage, one accelerated campaign with friends. Decide inactivity and elimination rules.

## Milestone 4 — Month-scale validation

Run simulated 28-day campaigns, tune operation durations and snowballing, measure dominant faction/first-mover effects, then a real-time campaign. Validate frequency of required interventions before adding depth.

## Milestone 5 — Strangers

PostgreSQL hosting, session lifecycle and abuse controls, public matchmaking, moderation/reporting, operational monitoring, and a deliberate diplomacy policy. Separate victory modes come later.
