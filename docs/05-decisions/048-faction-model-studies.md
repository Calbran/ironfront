# 048 — Faction model studies

## Accepted direction — 2026-09-10

The owner approved the next proof batch: three provisional faction signatures and combat engineers, using the existing military model scale.

## Implemented

- Iron Directorate: longer/wider heavy landship with side guns, central rotating turret, heavy steel, red markings and twin exhausts.
- Crownward League: six Armored Guards using actual infantry bodies, blue coats, breastplates, brass shoulder trim and helmet crests.
- Aether Compact: compact teal twin-turbine gunship with copper boiler, glazed cabin, landing skids and chin gun. Named turbines animate in the preview.
- Shared engineers: six existing-sized soldiers with spades, strapped tools, equipment packs and a field toolbox.

The existing preview selector and GLB export include all four. Faction metadata, named nodes and measured dimensions are exported. Squad bodies are not enlarged; city integration still requires the same uniform 0.55 transform as the city infantry. Full kits contain 720–2,740 triangles per asset.

## Provisional and deferred

Faction names/rosters remain provisional as in the thematic document. Squad composition and equipment are presentation choices. These are static model proofs; no faction recruitment, engineer construction, gunship flight, cover, suppression, or landship combat rules are introduced. Existing articulation and instance rendering remain the path for eventual live integration.
