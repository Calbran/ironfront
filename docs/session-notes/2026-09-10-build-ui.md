# Construction UI first pass
Implemented the five requested emplacement choices and local placement workflow with rotation, preview validation, cancellation and undo. Menu auto-collapses after choosing an item to keep ground accessible, including narrow views. Uses low-detail geometry with instanced sandbags, wire posts and trench supports. Prototype limitations are visible in the menu.
Validation: 222 regression tests pass, typecheck and build pass. Browser verified opening the menu, sandbag placement, undo removal and rotated artillery placement. Artillery remains staged in the courtyard for review. No firing, supply or tactical-obstacle integration is claimed.
