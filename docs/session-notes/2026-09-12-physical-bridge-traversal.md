# Physical bridge traversal

The country bridge had multiple conflicting height implementations. The rendered box used terrain at the river center, the road created its own eight-unit ramp, ground units used a hard-coded 0.4-unit floor, navigation graded the submerged terrain, and roadside detail repeated another deck estimate. At the generated crossing the river-bed center was -2 while the old deck top was only 0.395, which made the bridge nearly coincide with the water and let overlays visibly pass through it.

`countryRoadNetwork.ts` now owns bridge-local coordinates, deck containment, deck elevation and the ramped travel surface. The deck top clears water and samples both banks; a twelve-unit ramp blends each approach. Country road ribbons, the thicker deck and rails, roadside detail, country unit/path height and navigation grade checks consume that shared surface. Infantry and tanks remain constrained by their radius inside the deck width. Water outside an explicit bridge remains blocked.

Verification includes 15/15 focused road/sector tests covering deterministic deck/ramp/clearance behavior, generated-sector unit height and routing, plus typecheck, production build and a live 20× landship crossing from one bank to the other. The existing bundle-size advisory remains. A concurrent full-suite run completed 334/336; a filtered rerun identified failures in the separately added `campaign-encounter.test.ts` fixture (`undefined.region`), not in bridge, road or country-slice coverage. That concurrent campaign-encounter work remains outside this change.
